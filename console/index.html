                    配置类型: 0x03
                    16 字节: [0x03] [网络名称×15, null-terminated ASCII]
                

                

                    

                        
                        
                        15 bytes 有效, 以 0x00 结尾
                    

                

                

                    0x03 预览: 
                    03 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00
                

                

                    
                    
                

            


            
            

                

                    协议: 0x21 开始 → 0x20 数据块×74 → 0x22 提交
                    图片存在设备 Data-Flash(1024 字节 + 8 字节头), 不占代码区
                


                

                    

                        
                        
                        PNG/BMP/JPEG 等浏览器能解码的格式; 自动缩放到 128×64
                    

                    

                        
                        
                        图比 128x64 大时用"选区框选"自己挑一块要的部分
                    

                


                

                    选区裁切(比例锁死 2:1, 与 128x64 同比例, 缩过去不变形)
                    框内拖动 = 移动; 拖四角 = 缩放; 松手后重新生成二值图
                

                

                    
                    

                        
                        
                    

                


                

                    色阶(灰度预处理, 在二值化之前; 全部保持默认 = 不做任何处理)
                    顺序: 黑白场拉伸 → 伽马 → 对比度/亮度
                

                

                    

                        
                        
                        不高于该灰度的像素压成纯黑 · 当前 0
                    

                    

                        
                        
                        不低于该灰度的像素拉到纯白 · 当前 255
                    

                    

                        
                        
                        中间调明暗(100 = 1.0 不变) · 当前 1.00
